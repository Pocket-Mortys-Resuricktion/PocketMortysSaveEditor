📲 Deploy to Device
⚠ BEFORE YOU DO ANYTHING — READ THIS
1. Save a backup of your original Player.dat first — keep it somewhere safe. If something goes wrong you can restore it.
2. Delete CloudContainer.dat — this file syncs from the cloud and will silently overwrite your edited save the moment the game launches. You must delete it every time before loading the game.
    Location: Android/data/com.turner.pocketmorties/files/CloudContainer.dat
3. Cloud sync warning — After replacing the file the game may show a list of saves — the top entry is usually your local save. Pick that one. Choosing a cloud entry will overwrite your edits.
📱 Android — File Manager (no PC needed)
This method works directly on your phone using a file manager app. How easy it is depends on your Android version:
ANDROID 10 OR OLDER — SIMPLEST METHOD
1. Click Save Modified File below — this downloads your edited Player.dat to your phone's Downloads folder.
2. Open any file manager app (the stock "Files" or "My Files" app is fine).
3. Navigate to: Internal Storage → Android → data → com.turner.pocketmorties → files
4. Delete CloudContainer.dat from that folder.
5. Copy your edited Player.dat from Downloads into that same folder, replacing the existing one.
6. Open Pocket Mortys. Done!
ANDROID 11–13 — MAY NEED A SPECIAL FILE MANAGER
Google started blocking access to Android/data/ in Android 11. Your stock file manager probably can't open it anymore. Try this:

1. Install ZArchiver (free on Play Store) — it can still access that folder on many Android 11–13 devices.
2. Follow the same steps as above, using ZArchiver to navigate to the com.turner.pocketmorties/files folder.
3. If ZArchiver also fails, use the Shizuku method below.
ANDROID 14+ — SHIZUKU + FV FILE MANAGER METHOD
Google fully locked down Android/data/ on Android 14+. You need two free apps to get around this without rooting.

What you need:
• Shizuku (free — search Play Store, or get it from shizuku.rikka.app)
• FV File Manager (free — search Play Store)

Step 1 — Set up Shizuku (one time only):
  a. Install Shizuku and open it.
  b. Tap "Start via wireless debugging".
  c. It will ask you to go to Developer Options. If you don't have Developer Options visible: go to Settings → About Phone, then tap Build Number seven times in a row. You'll see "You are now a developer!"
  d. Go to Settings → Developer Options → Wireless Debugging and turn it on.
  e. Go back to Shizuku and tap "Pair using pairing code". A code will appear — go back to Wireless Debugging, tap "Pair device with pairing code" and enter the code.
  f. Back in Shizuku, tap "Start". You should see "Shizuku is running".

Step 2 — Grant FV File Manager access:
  a. Open FV File Manager and follow its prompt to enable Shizuku support.
  b. Grant the permission when asked.

Step 3 — Replace the save file:
  a. In FV File Manager, navigate to: Android → data → com.turner.pocketmorties → files
  b. Delete CloudContainer.dat.
  c. Copy your edited Player.dat from Downloads into this folder, replacing the old one.
  d. Open Pocket Mortys.

Note: You need to restart Shizuku after rebooting your phone. Just open Shizuku and tap Start again.
🖥 Android + PC — ADB Commands
This method uses a PC and a USB cable. It works on all Android versions and you don't need to install anything on your phone beyond enabling one setting.
SETUP — ONE TIME ONLY
1. On your phone: go to Settings → About Phone, tap Build Number seven times to unlock Developer Options.
2. Go to Settings → Developer Options and turn on USB Debugging.
3. On your PC: download ADB (platform-tools) from Google: developer.android.com/tools/releases/platform-tools
4. Extract the zip. You'll run commands from inside the platform-tools folder.
5. Connect your phone to your PC with a USB cable. On your phone, tap Allow when it asks to trust the computer.
DEPLOY STEPS
1. Click Save Modified File below. Move the downloaded Player.dat into your platform-tools folder.
2. Open a terminal / command prompt inside that folder.
   Windows: hold Shift and right-click inside the folder, pick "Open PowerShell window here"
   Mac/Linux: open Terminal and cd to the folder
3. Delete CloudContainer.dat:
adb shell rm /sdcard/Android/data/com.turner.pocketmorties/files/CloudContainer.dat
4. Push your edited save:
adb push Player.dat /sdcard/Android/data/com.turner.pocketmorties/files/Player.dat
5. Open Pocket Mortys on your phone. Done!
BACKUP ORIGINAL FIRST (recommended)
adb pull /sdcard/Android/data/com.turner.pocketmorties/files/Player.dat Player.dat.bak
🍎 iPhone / iPad — iMazing Method
iOS locks app data down tightly. The easiest no-jailbreak method is using iMazing, a paid desktop app (Mac & Windows) that lets you access and edit app files through iTunes backups. A free trial is available.
STEPS
1. Download and install iMazing on your PC or Mac from imazing.com.
2. Connect your iPhone/iPad to your computer with a USB cable.
3. Open iMazing. Your device should appear in the sidebar — click it.
4. Click "Manage Apps" (or browse to the Apps section).
5. Find Pocket Mortys in the list and click it.
6. Click "Copy to Mac/PC" to back up the app data first — save it somewhere safe.
7. Now click "Add to App" (or drag and drop your edited Player.dat into the app's Documents folder).
8. Navigate inside the app's files to the save folder. Replace Player.dat with your edited version.
9. Also delete CloudContainer.dat if it's there.
10. Click Done / Sync to push the changes back to your device.
11. Open Pocket Mortys.

Note: The exact iMazing UI varies slightly by version. Look for "App Files", "Documents", or the file browser for Pocket Mortys. If iMazing doesn't show app data for Pocket Mortys, the app may not support file access through iTunes backup — in that case a jailbreak would be required to access the save file directly.
JAILBREAK NOTE
If you have a jailbroken device, you can access the save file directly at /var/mobile/Containers/Data/Application/[UUID]/Documents/ using a file manager like Filza. Replace Player.dat and delete CloudContainer.dat as usual.
